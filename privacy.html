Privacy Policy

How the Stockan Chrome extension handles your information.

About this policy

This policy explains how the Stockan Chrome extension ("Stockan", "the extension") handles information. The extension is published by Dipak Das (Stockan), Town Silchar, District Cachar, Assam, India, PIN 788014. Contact: contact@stockan.in.

1. What Stockan is

Stockan adds educational analysis tools to the Zerodha Kite web platform (kite.zerodha.com): option-chain analytics, an order-flow footprint, chart studies, index flow, news sentiment, MTM alerts and paper trading. It is for educational purposes only. It is not affiliated with Zerodha, Google, NSE or BSE.

2. In short

  • Stockan runs inside your browser. Your Kite and Gemini keys, login session, positions, orders and trades never leave your device except to Zerodha and Google as described below.
  • We (the publisher) receive only anonymous usage statistics and error reports (section 6), which you can switch off in Settings. We do not sell, rent or share them.
  • There are no advertisements and no third-party analytics.

3. Information stored on your device

The following is stored in your browser (Chrome extension storage and, for settings shown on Kite pages, the browser's local storage for kite.zerodha.com). It never leaves your device except as described in section 4.

  • Your Kite Connect API key, API secret, redirect URL and the login session token. You type these in; they are used only to talk to Zerodha.
  • Your optional Google Gemini API key.
  • Settings (language, theme, MTM limits and similar), the analysis you ran today, paper-trading records, and cached public data such as index constituents, lot sizes and index volume history.
  • A random installation identifier created on your device. It is sent with the anonymous usage statistics (section 6) so that installs can be counted; it cannot be linked to your name, Zerodha account or trades.

You can remove the keys in Stockan Settings, or remove everything by uninstalling the extension or clearing your browser's site data. Chrome does not encrypt extension storage: treat your API secret like a password and revoke the Kite Connect app at developers.kite.trade if you stop using Stockan or lose control of your computer.

5. Permissions the extension asks for

  • storage / unlimitedStorage: keep your settings, today's analysis and the cached data above on your device.
  • notifications: show MTM stop-loss and target alerts.
  • tabs: open and close the Kite login tab and see the address of kite.zerodha.com tabs.
  • scripting: switch Stockan on or off inside open Kite pages.
  • declarativeNetRequestWithHostAccess: set the Referer header that BSE's public index API expects.
  • Site access to kite.zerodha.com, api.kite.trade, ws.kite.trade, news.google.com, nsearchives.nseindia.com, api.bseindia.com, generativelanguage.googleapis.com, and 127.0.0.1 (the Kite Connect login redirect).

Stockan does not download or run remote code. It only reads data and settings.

6. Anonymous usage statistics and error reports

To learn how many people use Stockan and which parts are useful, the extension contacts the Stockan server (hosted on Cloudflare) about every 3 hours while Chrome is open. This is sent:

  • the random installation identifier, the extension version, and the type of browser and operating system;
  • counts of how often a feature was used (for example "chart opened: 3", "AI Analysis: 1"). Only a fixed feature name and a number, never what you looked at;
  • anonymous technical error reports: error text with numbers, keys and addresses removed;
  • the server sees your IP address as with any web request, and derives an approximate location (country, region, city) from it. The IP address itself is not stored (only a one-way hash may be kept briefly to block abuse).

Never sent: your Kite or Gemini keys, login session, positions, orders, balances, trades, watchlists, prices or symbols you view, your name or e-mail.

You control it: Settings, "Send anonymous usage statistics and error reports". When switched off, nothing is counted and nothing is sent. The server may also send feature switches and update notices to the extension; this is data only, not code.

Statistics are kept in a Cloudflare database owned by the publisher and are used only to understand and improve Stockan.

7. How we use information

Only to provide the features you see. We do not use or transfer user data for advertising, for credit or lending decisions, or for any purpose unrelated to the extension's single purpose. The use of information received by the extension follows the Chrome Web Store User Data Policy, including its Limited Use requirements.
