Setup Guide

Connect Stockan to Zerodha Kite in four steps.

What you need

  • A Zerodha account and the Chrome browser.
  • A Kite Connect app from Zerodha (a paid Zerodha product) to get an API key and secret.
  • Optional: a free Google Gemini API key from aistudio.google.com for the AI explanation.

Step 1. Install

Install Stockan from the Chrome Web Store, then open kite.zerodha.com and log in to Kite as usual. A small "Stockan" tab appears on the left of the page.

Step 2. Create the Kite Connect app

  1. Open developers.kite.trade and create an app.
  2. In the field Redirect URL paste exactly the address shown in Stockan (Stockan panel, Settings, Connections; the Copy button copies it). The default is http://127.0.0.1:5199/kd-callback.
  3. Save the app and note the API key and API secret.

Step 3. Connect Stockan

  1. Open the Stockan panel, go to Settings, and paste the API key and API secret into the Kite Connect boxes.
  2. Press Save and connect. A Kite login tab opens; log in. The tab closes by itself and Stockan shows Connected.
  3. Stockan reconnects by itself every day while you are logged in to Kite (Zerodha ends the session at 6 AM every morning).

Step 4 (optional). Gemini AI explanation

Paste your Gemini API key under Gemini (AI analysis) in Settings and press Save Gemini key. Without it the market check, probabilities, levels and rule-based ideas still work. The AI explanation is only requested when you press Analyse.

Using it

  • Option chain: open Option chain in Kite for analytics, signals and the strike profile.
  • Chart: open a chart, choose Order Flow and the Stockan indicators menu.
  • AI Analysis: press Analyse once; today's result is saved in your browser and Reset clears it.
  • Buy / Sell: the buttons only open Kite's order window. You confirm there.

Safety

  • Your keys stay in your browser and are sent only to Zerodha (and the Gemini key only to Google). Read the Privacy Policy.
  • Treat the API secret like a password. If you stop using Stockan, remove the keys in Settings or delete the app at developers.kite.trade.

Troubleshooting

  • Not connected: check the Redirect URL in your Kite Connect app is identical to the one in Stockan, then press Save and connect again.
  • Nothing changes on Kite: reload the Kite tab.
